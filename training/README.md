# Fall-risk detector training

Trains the AI that warns about **stairs, curbs, holes, cracks and things on the floor** for Wayfinder.

## Start training

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/morrisraybrooks/wayfinder/blob/master/training/Wayfinder_FallRisk_Training.ipynb)

1. Click the button above.
2. Menu **Runtime → Change runtime type → T4 GPU → Save**.
3. Menu **Runtime → Run all**. Allow Google Drive when asked.
4. If Colab disconnects, open it again and **Run all**. It resumes from the last checkpoint saved in Google Drive → `Wayfinder`.

When it finishes, Google Drive → `Wayfinder` has the phone model (`*_float16.tflite`, `*_float32.tflite`) and `labels.txt`.

## What it learns (23 labels)

stairs, curb, hole (potholes, cracks, open manholes), manhole, pole, trash can, cone, plant pot, chair, bench,
fence, bike rack, fire hydrant, electrical box, bag, ball, skateboard, person, animal, bicycle, vehicle, tree, crosswalk

## Files

- `Wayfinder_FallRisk_Training.ipynb`: the Colab notebook. It's generated by `make_notebook.py`, so edit that file instead.
- `prep_data.py`: downloads and merges the photo sets into one YOLO dataset.

## Photo sets used

| Set | License | What it adds |
|---|---|---|
| [ROD-Dataset](https://huggingface.co/datasets/Abtinzandi/Obstacle-Detection-Dataset-YOLO) | MIT | 24k sidewalk photos: stairs, poles, bins, chairs, cones… |
| [Unified Obstacles](https://huggingface.co/datasets/Dderedor/obstacles_on_the_road) | MIT | curbs, sidewalk cracks, potholes, open manholes |
| [COCO 2017](https://cocodataset.org) (8,000 photos) | CC BY 4.0 | indoor floor things: bags, balls, skateboards, pets |

The model starts from [Ultralytics YOLO11n](https://github.com/ultralytics/ultralytics) (AGPL-3.0).

**Safety:** this is an extra warning, not a replacement for a cane or guide dog.
